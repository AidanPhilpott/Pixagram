# Benchmark images

Preset-preview benchmark images for the preset manager. Chosen to be
versatile — skin tones, whites/sky/foliage, and saturated color — so a
preset's character is visible at a glance.

Source: the **Kodak Lossless True Color Image Suite** (PhotoCD PCD0992),
released by Kodak for unrestricted usage and mirrored at
<https://r0k.us/graphics/kodak/> — the classic image-processing benchmark set.

| File | Kodak id | Subject |
|---|---|---|
| `portrait.jpg` | kodim15 | girl with face paint (skin tones) |
| `landscape.jpg` | kodim19 | lighthouse (whites, sky, grass) |
| `color.jpg` | kodim23 | two parrots (saturated reds/blues/yellows) |

Converted from the source PNGs to JPEG (quality 88) at the original
768×512 / 512×768 size.
